About this project

A standalone static site that ranks the top 100 digital AI companies — pure-play AI labs and the AI businesses of the megacaps — on one like-for-like basis.

What this is

This is a static website that ranks the top 100 digital AI companies as of October 2026 — pure-play AI labs and the AI businesses of the megacaps, on one like-for-like basis. The ranking is generated by a small Python script (scripts/score.py) that operates on a data/companies.json dataset. The website is a plain HTML / CSS / JS bundle — no build step, no backend, no dependencies beyond fetch.

Source taxonomy

The dataset was compiled in October 2026 from a mix of:

  • Public-market filings (10-K, 10-Q, S-1).
  • Confirmed funding rounds from TechCrunch, Reuters, Bloomberg, The Information, FT, WSJ, Forbes, Sifted.
  • Company announcements and IPO prospectuses.
  • Aggregations: Forbes AI 50, Startup-Oasis, CB Insights, PitchBook, Crunchbase.

How to re-run the ranking

Edit data/companies.json, then:

$ python scripts/score.py

The script regenerates data/ranked.json, data/ranked.csv, and the site-level ranked.json that the browser fetches.

Two analysis scripts back the robustness sections: scripts/sensitivity.py (log vs raw normalisation) and scripts/multiple_check.py (stress-tests the 20× peer multiple). Both write JSON into data/, which the overview page reads directly.

A third script, scripts/coverage.py, audits coverage. Every name on a watchlist (data/coverage_watchlist.json) must resolve to exactly one disposition — ranked, folded into a roll-up row, or excluded with a published reason. A name with no disposition is a coverage gap and blocks publication. The audit currently reports 39 of 39 names resolved and zero gaps.

Tech used

  • Python 3.10+ for the scoring script (standard library only).
  • Plain HTML, CSS, vanilla JavaScript for the site.
  • Hosted as a static site on GitHub Pages.
